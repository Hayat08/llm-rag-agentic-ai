# TP1 - LLM & Prompting

Application locale d'extraction d'informations structurées à l'aide d'un petit LLM.

## Objectifs
- Appeler un LLM local avec Ollama.
- Tester différentes stratégies de prompting.
- Extraire des relations entre entités.
- Évaluer les résultats et la validité du JSON.
